# 🌙 Mondkurier

Ein kleines Browser-Minispiel: Als Kurierkatze springst du über Schornsteine und Dachlücken der nächtlichen Skyline, bevor der Mond untergeht.

## Spielen

Einfach `index.html` in einem beliebigen modernen Browser öffnen — kein Build-Schritt, keine Abhängigkeiten.

## Steuerung

- **Leertaste**, **Pfeil hoch** oder **Klick**: Springen
- Erneut drücken für einen Doppelsprung

## Ziel

Sammle so viele Pakete wie möglich, bevor die Zeit abläuft. Jedes zugestellte Paket gibt dir zusätzliche Sekunden. Dein Highscore wird lokal im Browser gespeichert.
